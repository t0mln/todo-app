# Todo App

## Goal

Build a full-stack todo application where a user can create,
view, update, complete, and delete tasks.

## Core Features

- Create a todo
- View todos
- Update a todo
- Mark a todo as completed
- Delete a todo

## Todo

Each todo should have:

- id
- title
- completed
- created_at
- updated_at

## Technology

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express

Database:
- PostgreSQL

Optional:
- React
